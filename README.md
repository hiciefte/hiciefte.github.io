# hiciefte.github.io

This site exists only to keep old links working. The Bisq documentation preview that was at
`https://hiciefte.github.io/bisq-docs/` moved to
[bisq-network.github.io/documentation](https://bisq-network.github.io/documentation/) on 10 November 2026.

`404.html` sends any `/bisq-docs/...` path to the same path at the new address, keeping the query and
the `#section`. Every other path shows a short "Page not found" note. The target origin is fixed in the
script, so the page cannot be used as an open redirect.

Source: `transfer/hiciefte.github.io/` in
[bisq-network/documentation](https://github.com/bisq-network/documentation).
